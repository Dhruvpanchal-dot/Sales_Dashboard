Sales Dashboard 

Project Title : Sales Dashboard for Awesome Chocolates

Project Overview : 
This project elaborates on the total sales which helps the company gain insights which helps in taking better decisions

What does it contribute:
It helps stakeholders find out which country's sales are highest or lowest, which salesperson ships more boxes, etc 

Total Sales ($43.56M)

LBS % (9.56%). Define this one clearly, since a recruiter will ask what it means.

Visuals used and why:
Bar chart, Total Sales by Geo: compares regions.
Area/line chart, Total Sales by Month: shows the trend.
Donut chart, Boxes by Geo: shows each region's share of volume.
Table, Salesperson vs Total Boxes: shows individual performance.
KPI cards: give the headline numbers at a glance.
